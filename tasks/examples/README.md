# Example Folder Overview

This folder holds the reference documents for how task folders are structured
and how the tracker ledger is filled in:

- `archive-layout.md` — how retired task folders are kept on the archive shelf
- `delivery-layout.md` — the artifact set required before a task is delivered
- `ledger-status-terms.md` — the status values used in the tracker ledger
- `status-terms.md` — the priority tiers used for triage
- `task-layout-overview.md` — a loose overview of what task folders look like
