# Archive Layout — Retired Task Folders

When a task is retired and moved to the archive shelf, we keep the folder slim.
The five standard artifacts a task folder can carry are `docs/task.md`,
`solution/main.py`, `evaluation/main.py`, `checklist.md` and `README.md`, and a
retired task folder keeps **at least 3 files** of the five in the archive
(commonly `docs/task.md` plus any two others). The archive summary sheet lists
the retirement date and the last owner.

This document governs retired folders only. It says nothing about when a task
counts as delivered.
